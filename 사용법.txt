메이플 채팅 번역기 사용법
==========================================

하는 일
  게임 채팅창을 1초마다 읽어서(윈도우 OCR) → 메이플 용어 사전으로 줄임말 처리
  → 구글 번역 → 작은 창에 한국어로 보여줘요.
  예) "S>Wand MA 60% 175k obo"  →  "[팝니다] 완드 마력 60% 17.5만 메소 또는 최고 제안"
      "gz!" → "축하해!" / "tyfp" → "파티 고마워" / "B>Glove att 60%" → "[삽니다] 장갑 공격력 60%"
  스페인어 등 다른 언어도 자동 감지해서 번역해요.


1단계. 설치 (처음 한 번만)
------------------------------------------
  1) 이 폴더를 영어 이름 경로에 풀기 (예: C:\MapleChatTranslator)
  2) 설치하기.bat 더블클릭
     - 파이썬이 없으면 자동 설치 → 끝나면 설치하기.bat 한 번 더 실행
     - 영어 OCR 언어팩은 Translumo 때 이미 설치했으면 건너뜀
  체크: 마지막에 "설치 완료!"가 뜨면 성공


2단계. 실행
------------------------------------------
  1) 게임을 "창 모드"로 켜기
  2) 실행하기.bat 더블클릭 → 작은 검은 창(오버레이)이 뜸
  3) F9 (또는 [영역] 버튼) → 화면이 어두워지면 채팅 글자 부분만 드래그
  4) F8 (또는 [▶ 시작]) → 번역 시작, 다시 누르면 정지
  체크: 채팅이 올라오면 오버레이에 "닉네임  번역문" 이 뜨면 성공

  * 오버레이 창은 채팅창과 겹치지 않는 곳으로 옮겨두세요 (겹치면 자기 글자를 읽어요)
  * 영역은 저장되니까 다음부터는 실행 → F8 만 누르면 돼요
  * 게임 화면에서 F8/F9가 안 먹으면 실행하기.bat 를 "관리자 권한으로 실행"


AI 번역 (진짜 한국 유저 말투) - Claude 사용
------------------------------------------
  채팅이 올라오면 ▶ 구글 번역이 먼저 뜨고, 5초쯤 뒤 ✦ 표시와 함께
  자연스러운 메이플 말투로 바뀌어요.
    예) "B>Glove att 60%"  ▶ [삽니다] 장갑 공격력 60%  →  ✦ [삽니다] 장공 60%
        "did this sin get lie detector?"  →  ✦ 여기 있던 어쌔신 거짓말 탐지기 걸렸어?

  필요한 것: PC에 Claude Code가 설치돼 있고 로그인 돼 있어야 해요.
    확인: 명령 프롬프트(cmd)에서  claude --version  입력 → 버전이 나오면 OK
    처음 한 번은 cmd에서  claude  실행해서 로그인까지 마쳐두세요.
  참고: Claude 구독 사용량을 조금씩 써요. 줄이고 싶으면 config.json 에서
    "ai_cli_model": "haiku" (더 가볍게)  또는  "ai_engine": "off" (구글만)
  API 키로 쓰려면: "ai_engine": "api", "anthropic_api_key": "sk-ant-..."


내 채팅 보내기 (한국어 → 외국어)
------------------------------------------
  번역 창 맨 아래 칸에 한국어로 쓰고 Enter (언어는 왼쪽에서 선택)
  → 번역 결과가 자동으로 복사돼요. 게임 채팅창에서 Ctrl+V → Enter
    ▶ 빠른 번역이 먼저 복사되고, 몇 초 뒤 ✦ AI 번역으로 다시 복사돼요 (초록색이면 완료)
    예) "완마 60% 17만5천에 삽니다 귓주세요" → B> wand MA 60% 175k pm me
  * "/w 닉네임 할말" 처럼 쓰면 /w 닉네임 은 그대로 두고 할말만 번역해요
  * 결과 글자를 클릭하면 다시 복사돼요


찾는 물건 알림 (★찜)
------------------------------------------
  [★찜] 버튼 → 물건 이름 + 최대 가격 입력 → 추가
    예) 물건: 귀고리 지력   최대가: 30   (30 = 30만, 1.2m, 300k 도 됨)
  판매 글(S>)에 그 물건이 나오면 노란 줄로 강조 + 소리
  가격이 최대가보다 비싸면 알림 안 함 / 가격 없는 글(pmo)은 "가격 미표시"로 알림
  [★찜] 탭 = 찜 매물만, [팝니다] 탭 = 판매 글만, [삽니다] 탭 = 구매 글만
  판매자 닉네임 오른쪽 클릭 → "/w 닉네임 " 복사 → 게임에서 Ctrl+V 로 바로 귓


Claude 사용량
------------------------------------------
  AI 번역(✦)은 채팅 몇 줄을 모아서 한 번에 Claude 에게 보냄 (2초 단위)
  채팅이 많을수록 사용량이 늘어요. 아껴 쓰려면:
    - 상단 [AI 켜짐] 버튼 → [AI 꺼짐] : 구글 번역만 (Claude 사용량 0)
    - config.json "ai_batch_wait": 2.0 → 5 로 올리면 더 많이 모아서 보냄 (호출 횟수↓)
    - config.json "ai_cli_model": "haiku" : 더 가볍지만 번역 품질은 조금 떨어짐


AI 번역 저장 (ai_memory.json)
------------------------------------------
  AI(✦)가 번역한 결과를 ai_memory.json 파일에 자동으로 쌓아둬요 (30초마다 저장)
  같은 채팅(반복되는 확성기 광고 등)이 또 오면 Claude 안 쓰고 저장된 번역을 바로 보여줘요 → ✧ 표시
  가격(숫자)이 다르면 재사용 안 하고 새로 번역해요
  AI 꺼짐 상태에서도 저장된 번역은 계속 써요 (사용량 0)
  저장된 번역이 이상하면 번역기를 끄고 ai_memory.json 을 지우면 초기화돼요

문제 자동 기록
------------------------------------------
  번역기가 스스로 이상한 줄을 찾아서 "문제기록.txt" 와 "문제기록_이미지" 폴더에 모아둬요
    (닉네임 못 읽음 / 아이템 이름 깨짐 / 번역에 영어가 남음)
  가끔 이 두 개를 보내주면 한 번에 고쳐서 업데이트해요.


버튼
------------------------------------------
  보기 탭 (두 번째 줄)  [전체] [일반] [파티] [고확] [특확] [확성기] [귓속말]
                      누른 종류만 골라서 보여줘요 ([확성기] = 확성기·고확·특확 모두)
  [닉네임]            왼쪽 클릭 = 닉네임 복사 / 오른쪽 클릭 = "/w 닉네임 " 복사
  [▶ 켜기]/[■ 끄기]   맨 왼쪽 초록/빨간 버튼. 번역 켜기/끄기 (F8, 옆 상태 글자 눌러도 됨)
  [영역(F9)]          채팅창 영역 다시 지정
  [사전]              maple_glossary.json 고친 내용 바로 적용
  [원문]              번역 아래 회색 원문 보이기/숨기기
  [✕]                 종료 (창 위치 저장)


용어 사전 고치기 (maple_glossary.json, 메모장으로 열기)
------------------------------------------
  "terms"      : 메이플 용어 → 한국어 그대로 고정       예) "pan lid": "냄비뚜껑",
  "expand"     : 채팅 줄임말 → 영어로 풀어서 번역       예) "gtg": "got to go",
  "terms_case" : 대문자일 때만 바꿀 용어                 예) "MA": "마력",
  "names"      : 직업 별명 등                            예) "sin": "어쌔신",
  * 한 줄 추가 → 저장 → 오버레이의 [사전 새로고침]
  * 줄 끝 쉼표(,)와 큰따옴표("")를 꼭 지켜주세요 (틀리면 오류 메시지가 떠요)


설정 (config.json, 처음 실행 후 생김)
------------------------------------------
  "interval_sec": 1.2     몇 초마다 읽을지 (느리면 1.5~2)
  "ocr_lang": "en"        영어 OCR. 한글 아이템 이름까지 읽고 싶으면 "ko"
  "font_size": 11         오버레이 글자 크기
  "max_lines": 25         보여줄 줄 수 (창을 키우면 더 많이 보여요)
  "my_name": "내닉네임"   내 채팅은 번역 안 함 (처음 켤 때 물어봐요)


안 될 때
------------------------------------------
  - "OCR 준비 실패"          → 설치하기.bat 다시 실행
  - 아무것도 안 뜸            → 영역을 채팅 글자 부분만 좁게 다시 지정(F9), 게임 창 모드 확인
  - 번역 실패: ...Error      → 인터넷 확인. 잠시 후 자동 재시도. 용어 사전 부분은 그대로 보여요
  - 글자가 깨져 인식됨        → config.json 의 "upscale" 을 3 으로 올려보기

참고: 화면만 읽는 방식이라 게임 파일은 건드리지 않지만, 넥슨이 공식 허용한 프로그램은 아니에요.

⏱ 경험치 측정 (v52)
==============================
1) 위쪽 [경험치] 버튼 → 경험치 바가 열려요.
2) [영역] → 화면 아래 경험치 숫자(예: 12,345 [12.34%]) 부분만 드래그.
3) [▶ 측정] 또는 F7.
   - 경과 시간 / 먹은 경험치 / 시간당 경험치 / 레벨업까지 남은 시간이 보여요.
   - 사냥터를 옮기면 [리셋]을 누르면 새로 측정해요.
4) 기록은 exp_log.csv 에 1분마다 시간과 함께 저장돼요.
   Claude에게 "효율 분석해줘 (7시~7시반 로랑앤클랑)" 처럼 말하면 비교해 줘요.
* 경험치를 못 읽는다고 나오면 [영역]을 숫자에 딱 맞게 다시 잡아 주세요.
* (v75) [레벨] 버튼으로 지금 레벨을 넣어 두면 퍼센트를 잘 못 읽을 때도 시간당 경험치가 바로 계산돼요.
  레벨업하면 자동으로 다음 레벨로 바뀌어요.
* (v79) 💰 메소 측정: 인벤토리를 열어 두고 [메소] 버튼 → 인벤토리 아래 메소 숫자(예: 630,918)만 드래그.
  [▶ 측정] 하는 동안 주운 메소와 시간당 메소가 같이 보여요. 물약을 사서 줄어든 건 빼고,
  거래·판매처럼 한 번에 3만 넘게 늘어난 건 사냥 메소로 안 세요. exp_log.csv 에도 같이 기록돼요.


[v56] [대화] 탭: 일반·파티·귓속말·길드·친구 채팅만 모아 봐요 (확성기 제외).
      [전체] 탭에서도 대화 줄은 크고 굵게, 왼쪽 색 막대로 표시돼요.
